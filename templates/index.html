Schedule syntax
          
frame: prompt or seconds s: prompt (video time, e.g. 2.5s). Frame numbers count processed frames from Start. Each line holds until the next one, and the style prompt above is added to every line.
          After a | you can set denoise=, cfg=, steps= (eased linearly between the lines that set them) and seed= (from that line on).
          Prompt blend cross-fades into each new line over that many frames, and Color lock and Identity anchor take a fresh reference from the first frame of each line.

Motion tolerance

      
Frame preservation warps the last stylized frame along the video's motion and starts the next frame from it. Identity anchor does the same from the first frame of the current prompt line. Motion tolerance: how different a region may look before it counts as new and is redrawn from the source.

Prompt blend

      
      
Keyframe every N: only every Nth frame is diffused; the frames between are the two neighbouring keyframes warped along the motion and blended (N times faster, and very steady). Interpolate adds motion-compensated in-between frames to the finished video for smoother playback.
